# 海南本地开发者网站 Implementation Plan

**Goal:** 制作以真实案例为核心、可直接部署到 GitHub Pages 的项目承接网站。
**Architecture:** 无构建静态单页；配置和案例数据独立；浏览器增强交互，原生链接可直接联系。
**Tech Stack:** HTML / CSS / JavaScript / Node 内置测试。
**Spec:** docs/design.md

## Global Constraints
- 所有页面资源使用相对路径，兼容仓库子路径。
- 只写入 home_web，不修改其他项目或根仓库的未提交内容。
- 真实素材与示意界面明确区分；不复制凭证或私有配置。

## Review Focus
- 无视频时展示截图，不加载不存在的视频。
- 分类结果正确，空分类行为清楚。
- 详情弹窗可用键盘关闭且归还焦点。
- 移动端导航能打开、关闭和跳转。
- 剪贴板不可用时仍能手动复制微信。
